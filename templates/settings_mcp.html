Connect an Agent

Connect an AI agent to your Jottit account via MCP. Your agent can create, read, and update pages on your profile.

Claude Code

Add Jottit as a remote MCP server. Claude Code will handle authentication via OAuth.

claude mcp add jottit --transport sse {{ base_url }}/mcp

Claude Desktop and other MCP clients

Generate a config with an API token and add it to your client's configuration file.


            
        

        
    


    

        
CLI

        
Publish pages from your terminal.

        

            
curl -fsSL https://jottit.org/install-cli | sh
jottit login
jottit publish page.md
